# Evidence Pack Export And Verify Example

This example captures a synthetic regulated output, exports an Evidence Pack, and verifies the Evidence Pack in local mock mode.

Mock Evidence Packs are useful for tests and examples. They are not externally trustworthy evidence and do not guarantee legal compliance.

## Install

```bash
python -m pip install -e .
```

## Run

```bash
python examples/evidence-pack-export-verify/example.py
```

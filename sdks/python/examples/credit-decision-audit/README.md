# Credit Decision Audit Example

This example captures and verifies technical regulatory evidence for a synthetic credit decision-support workflow.

AuthenChain provides provenance, integrity, traceability, audit, and dispute evidence. It does not make a credit decision and does not guarantee legal compliance.

## Install

```bash
python -m pip install -e .
```

## Run

```bash
python examples/credit-decision-audit/example.py
```
